# MD Vieditor

WYSIWYG Markdown editor for macOS.

## Build

Requires macOS 14+ and Command Line Tools (`xcode-select --install`).

```bash
git clone https://github.com/ilchats/md-vieditor.git
cd md-vieditor
bash build.sh
```

The app is installed to `~/Applications/MD Vieditor.app`.
